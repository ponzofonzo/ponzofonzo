### About this code

Throughout my career I've built tools like these for my employers. That code belongs to them and
stays with them. The projects below are generic versions that I wrote independently, from scratch,
for public use. They contain no employer source code, configurations, credentials, device data, or
internal information. They rely only on built-in macOS commands and publicly documented behavior.

Everything here is read-only by design, has no third-party dependencies, and comes with automated
tests.

| Project | What it does |
|---------|--------------|
| [jamf-extension-attributes](https://github.com/ponzofonzo/jamf-extension-attributes) | Ten tested Jamf Pro Extension Attributes for security posture and device health |
| [macos-security-audit](https://github.com/ponzofonzo/macos-security-audit) | FileVault, SIP, Gatekeeper, firewall, and access-control audit with JSON/HTML reports |
| [mac-health-inspector](https://github.com/ponzofonzo/mac-health-inspector) | Help-desk health diagnostics: disk, memory, battery, SMART, panics, MDM |
| [macos-update-readiness](https://github.com/ponzofonzo/macos-update-readiness) | Can this Mac take its pending updates? Checks space, power, and bootstrap token, and never installs anything |
